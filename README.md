# RPH Sains Tahun 4 — GitHub Pages

Web app static untuk memuatkan 2 RPH bagi setiap Minggu 1–43.

## Ciri
- 86 RPH daripada fail sumber.
- Mobile-friendly.
- Google Fonts (Poppins + Inter).
- Edit semua medan.
- Autosave ke `localStorage`.
- Reset satu RPH / satu minggu / semua RPH.
- Export & Import backup JSON.
- Cetakan A4: satu RPH = satu muka surat.

## GitHub Pages
1. Upload semua fail dalam folder ini ke sebuah repository GitHub.
2. `Settings` → `Pages`.
3. Pilih `Deploy from a branch`.
4. Pilih branch `main` dan folder `/ (root)`.
5. Save.
6. Buka URL GitHub Pages yang diberikan GitHub.

Tiada database atau server diperlukan.
